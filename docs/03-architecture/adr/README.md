# Architecture Decision Records

One file per decision, from [TPL-0001](../../02-templates/TPL-0001-adr-template.md), named `ADR-NNNN-<short-title>.md` per [STD-0002](../../00-standards/STD-0002-naming-conventions.md).

## Rules

- ADRs are **immutable after approval**. To reverse or amend a decision, write a new ADR with `supersedes: ADR-XXXX`; update the old ADR's front matter (`superseded-by`) and this index — nothing else in the old ADR changes.
- Numbering is chronological by creation, allocated via this index per [STD-0003 §4](../../00-standards/STD-0003-document-numbering.md).
- Approval per the [GOV-0002 matrix](../../01-governance/GOV-0002-approval-workflow.md): single-team ADRs need the team lead + one Architecture Board member; platform-scope ADRs need two board members + affected team leads.
