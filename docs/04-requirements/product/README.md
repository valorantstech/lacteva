# Product Requirements (PRD)

Product Requirements Documents define **what the product does for users**: personas, journeys, functional behavior with acceptance criteria, and success metrics. Each PRD traces to a BRD; each is realized by one or more SRSs.

- Template: [TPL-0003](../../02-templates/TPL-0003-product-requirements-template.md)
- Naming: `PRD-NNNN-<short-title>.md` per [STD-0002](../../00-standards/STD-0002-naming-conventions.md)
- Approval: product lead + owning engineering lead ([GOV-0002](../../01-governance/GOV-0002-approval-workflow.md))
