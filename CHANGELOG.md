# Changelog

All notable changes to this repository's structure, standards, and governance are recorded here. Individual documents carry their own change logs; this file tracks the **repository level**.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Repository versioning follows [STD-0004 Versioning Strategy](docs/00-standards/STD-0004-versioning-strategy.md).
