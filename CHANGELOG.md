## [0.1.0] - 2026-08-02

### Added

- Initial repository structure: `docs/` documentation workspace with 12 numbered domains, plus `services/`, `libs/`, `infra/`, and `tools/` roots for future code.
- Standards suite (STD-0001 … STD-0006): Markdown writing standards, naming conventions, document numbering, versioning strategy, Mermaid standards, PlantUML standards.
- Governance suite (GOV-0001, GOV-0002): review workflow and approval workflow.
- Template suite (TPL-0001 … TPL-0012): ADR, business requirements (BRD), product requirements (PRD), software requirements (SRS), API specification, database design, AI model card, event specification, business capability, domain model, glossary, and change log templates.
- Repository root documents: `README.md`, `CONTRIBUTING.md`, `CHANGELOG.md`, `.github/` PR template and CODEOWNERS.
- Company-wide glossary seeded with core dairy-domain and platform terms.
